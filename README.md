# ✈️ Автоматизация учета командировок (Trip Manager)

Приложение для автоматической обработки уведомлений о командировках из корпоративной почты (Outlook/Exchange). Программа читает входящие письма, извлекает данные о поездках, создает структурированные каталоги для отчетности и автоматически добавляет напоминания в календарь с учетом производственного календаря РФ.

## ✨ Основные возможности

- **Интеграция с Outlook (Exchange):** Автоматический сбор писем по заданным фильтрам (новые командировки, изменения дат/условий).
- **Парсинг данных:** Извлечение номера приказа, дат поездки, места назначения и цели из текста писем.
- **Управление файловой системой:** 
  - Автоматическое создание папок для каждой командировки в формате `01_10.01.2026-15.01.2026 (01-01-2026-1_К)/отчетка`.
  - Защита от дубликатов.
  - Автоматическая архивация папок прошлых лет.
- **Умные напоминания:** Создание событий в календаре Exchange с учетом выходных и праздничных дней (данные загружаются из актуального производственного календаря).
- **Фоновая работа:** Встроенный планировщик (`schedule`) для ежедневного запуска проверок.

## 🛠 Технологии

- **Язык:** Python 3.x
- **Библиотеки:** `exchangelib` (работа с Exchange), `pydantic` (валидация данных), `schedule` (планировщик), `pytest` (тестирование).
- **Архитектура:** Разделение на слои (Core, Integrations, Parsers, Models).

## ⚙️ Установка и настройка

### 1. Подготовка окружения
Склонируйте репозиторий и установите зависимости:
```bash
pip install -r requirements.txt
```

### 2. Настройка доступов (.env)
Создайте файл `.env` в корне проекта (рядом с `run.py`) на основе `env.example`. В нем должны быть указаны учетные данные для доступа к Exchange:
```env
EMAIL=ваш_email@example.com
PASS=ваш_пароль
SERV=адрес_сервера_exchange
```

### 3. Конфигурация приложения (config_mails.ini)
Скопируйте `config_mails.ini.example` в `config_mails.ini` и настройте параметры:
```ini
[files]
# Путь, где будут создаваться папки для командировок
TRIPS_BASE_PATH = C:\Path\To\Trips

[mails]
# Настройки смещения для напоминаний
START_LOCK = ...
END_LOCK = ...
START_NOTIFICATION = -7,-3,-1
END_NOTIFICATION = -1
```

## 🚀 Использование

Для запуска приложения в режиме постоянного мониторинга (по расписанию):
```bash
python run.py
```
*(Или запустите `run.pyw` для скрытого выполнения в Windows без окна консоли).*

### Сборка исполняемого файла (.exe)
Проект можно скомпилировать в один исполняемый файл для удобного запуска без установленного Python. Команда для сборки находится в файле `make_exe_command.txt`.

## 📂 Структура проекта

* `src/core/` — основная бизнес-логика (расчет напоминаний, обработка данных).
* `src/integrations/` — взаимодействие с внешними системами (Outlook, Файловая система).
* `src/models/` — структуры данных и Pydantic-схемы.
* `src/parsers/` — логика извлечения текста из писем.
* `src/utils/` — конфигурация, логгер, календарь.
* `data/` — локальный кэш производственных календарей.
* `tests/` — unit-тесты (запуск через `pytest`).
